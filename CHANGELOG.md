# Release notes

## Version [v1.0.0] - 2026-11-12

### Features
- new `GaussianUStatMMD` and `KernelUStatMMD` algorithms that are less biased than V-Statistic
- new `CUDAExt` extension: `GaussianVStatMMD` and `GaussianUStatMMD` on `Contiguous`-layout `CuArray` data is computed on the GPU

### Fixes
- fixed crash in `KernelMMDExt`


## Version [v0.2.1] - 2026-08-19

### Fixes
- automatic `max_dist` selection in `preprocess` for `Trajectories` properly respects the `lag`

### Enhancements
- faster cluster center computation in farthest point sampling
- reduced allocations in `preprocess` for `Trajectories`


## Version [v0.2.0] - 2026-08-17

### Features
- implemented equality and hashing for `TransitionDistanceProblem`
- new kwarg `lag` in `preprocess` for `Trajectories` to specify the snapshot lag

### Enhancements
- improved performance of farthest point sampling by ensuring type stability and adding multi-threading


## Version [v0.1.0] - 2026-07-08

Initial release.
